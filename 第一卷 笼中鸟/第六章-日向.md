# 第六章 日向

回村后的第三天下午，悠真去了族里的训练场。右臂还不适合重新加大雷刺激，普通步法和柔拳倒没什么影响。在外面跑了四个多月，他也需要把原来的训练节奏重新捡起来。

前面的场地已经有人占着。十几个孩子按年纪分成两排，正在练最基础的柔拳。脚步踩过夯实的泥地，衣袖随着出掌一阵阵扬起。负责教习的中年男人站在侧面，谁的肩膀抬高了，谁的脚尖偏出去一点，他走过去拨一下，人便重新站正。

悠真沿着训练场边缘往里走。靠外的一个孩子最先看见他，手里的动作慢了一拍。旁边的人顺着他的视线望过来，很快又有两三个脑袋转向这边。他们看的大多不是悠真的脸，而是他腰后那把短刀。

“眼睛往哪儿放？”场边传来一声呵斥。

几个人立刻转了回去。教习甚至没往悠真这边看，只让刚才动作停下的孩子重新来一遍，悠真也没有停步。

一轮训练结束，孩子们被放去喝水休息。刚才最先偷看的那个小孩却没有跟着人群走，而是跑到墙边，从外衣下面抽出一把木刀。

木刀削得不算好，刀脊一边厚一边薄，握柄上缠着一截旧布，长度倒是和悠真平时用的短刀差不多。几个孩子立刻围了过去。

“你真带来了？”

“昨天才弄好的。”小孩把木刀往腰后一别，特意往四周看了一圈。教习正在另一头跟几个年纪稍大的孩子说话，他这才往后退开几步，“看着。”

他脚下一蹬，猛地冲了出去。第一步确实很快，第二步便有些收不住。他还想学着悠真平时抽刀的动作，把木刀从腰后带出来，可手刚摸到刀柄，身体已经先向前栽了过去。

旁边几个人顿时笑成一片。小孩双手撑地，好不容易没摔个满脸灰，爬起来时耳朵已经红了：“笑什么！刚才不算！”

他把木刀重新插回去，第二次还没冲出去，一只手便从旁边伸来，直接将刀抽走。周围的笑声一下没了。

教习拿着木刀，低头看了几眼：“谁让你把这个带进来的？”

孩子刚才那股劲顿时散了大半：“我自己做的……”

“我问谁让你带进训练场。”

孩子没了声音。教习把木刀往他怀里一扔：“收起来。”

他抱住木刀，却没有动。犹豫了一会儿，还是忍不住往悠真离开的方向看：“可是悠真哥也用刀——”

教习的脸色沉了下来：“住口！别拿别人当借口。”他把木刀重新塞回孩子怀里，“扔出去。”

孩子仍抱着刀没动。直到教习问了一句“没听见？”，他才不敢再说话，低着头跑向墙外。

等人回来，教习扫过剩下几个孩子：“都看够了？”没有人出声。他的声音随即又沉了一些：“这里是日向的训练场。站在这里，就练日向的柔拳！”

他的视线落回刚才那个孩子身上：“再让我看见这种东西，你就直接出去。列队。”

孩子们立刻散开。随着一声“从头开始”，场上很快重新响起整齐的落步声。

悠真已经穿过后面的院门。他刚才走得不快，那几句话自然听见了，脚步却没有因此发生变化。再往里，训练场的声音被院墙挡住，很快只剩下一点模糊的动静。

悠真转过墙角，右侧忽然响起一声破风。他偏了偏头，一枚木制手里剑擦过耳边，撞在前面的木柱上，又弹落在地。

几乎同时，一个很小的身影从左边矮墙后冲了出来。右掌摆得有模有样，直奔悠真胸口。悠真退开半步，让第一掌落空；宁次已经跟着往前迈了一步，第二掌紧接着追上，又被他侧身避开。

宁次急忙收住脚，转过头来。几个月没见，小家伙似乎又长高了一点，一头黑发随着刚才的动作翘起几缕，浅色的眼睛正死死盯着悠真。

悠真看了眼掉在地上的木手里剑：“练了多久？”

宁次本来就因为没打中有些不高兴，听见这句话，更不愿意回答，只重新摆好架势。悠真也没有再问。

这一次，宁次没有马上扑过来。他先看了一眼悠真的脚，等了一会儿才突然往右侧冲。悠真脚下一动，宁次却在中途硬生生改了方向。小小的身体晃了一下，还是从另一侧追了上来。

动作算不上漂亮，但和刚才只知道往前追已经完全不同。悠真原本准备迈出的脚停了一瞬，就这一瞬，宁次已经贴近，手掌距离他的衣襟只剩一点。

宁次的眼睛顿时亮了。悠真前脚落下，身体却没有沿着他判断的方向继续后退。重心在落脚前微微一转，人已经从宁次手臂外侧绕了过去。

宁次眼前一空，还没来得及回头，额头上已经挨了一下。

啪。不重，却很响。

宁次捂住额头猛地转身，悠真正站在他后面。

“又是这个！”

看来以前没少挨。悠真收回手，宁次却揉着额头越想越不服，刚才明明就快碰到了。他往后退开两步，重新抬手：“再来！”

说完也不等悠真答应，人已经扑了上来。

“宁次。”

声音从一旁传来。宁次脚下一顿，整个人硬生生停在半路，悠真也抬起头。

日差站在廊下，应该刚结束自己的训练，额头还带着一点汗，右手正慢慢解开缠在腕上的护带。宁次看看父亲，又看看悠真，明显还有些不甘心，最后还是收了手：“父亲。”

日差朝他招了下手。宁次跑过去，经过地上的木手里剑时又折回去把东西捡上，这才站到父亲身边：“我刚才差一点。”

日差看了一眼他还微微泛红的额头：“我看见了。”

宁次立刻抬头：“真的就差一点。”

日差没有和他争，只用手掌在他后脑按了一下，把人往自己身边带了带，随后看向悠真。

院子安静下来。日差的目光在悠真身上停了片刻，最后落到他的脚下：“刚才那一下。”

悠真知道他说的是哪一下：“任务里慢慢改的。”

“嗯。”日差只应了一声，没有继续追问。他把刚刚解开的护带重新缠回腕上，动作并不快。等最后一圈勒紧，人已经从廊下走了下来。宁次抱着木手里剑站在后面，好奇地看着父亲。

日差在悠真面前两三步外停下，右手忽然抬起。没有摆架势，只是一掌平平送了过来。

悠真的身体先于思考作出反应。他脚下一错，肩膀让开掌锋，沿着日差右臂外侧切入。日差的左手却已经等在那里，速度与刚才的宁次完全不在一个层次。悠真前脚还没落稳，那只手便封住了他继续向前的位置，再走一步，正好送到掌下。

悠真没有继续，刚刚前压的重心骤然收回，鞋底擦过地面，人随之停住。下一瞬，他没有后退，原本收回的脚反而向内侧斜插半步，身体从日差两掌之间重新切出一个角度。

日差眉梢微微一动，手腕跟着转了半圈。

啪。

两人的手臂轻轻碰了一下，同时停住。从日差出手到结束，不过两息，宁次站在廊下，连姿势都没来得及换。

日差慢慢收回手，低头看了一眼自己刚才站的位置，又看向悠真。悠真也把手放下，两人都没有说话。

院门那边却不知什么时候多了几颗脑袋。刚才休息结束的几个孩子趁教习没注意，已经挪到了这边，最前面的正是那个拿木刀的，木刀还抱在怀里。

日差朝那边扫了一眼，几个脑袋立刻缩回去一半，却没有离开。他也没有管，只活动了一下刚才和悠真碰到的手腕，转头看向旁边那块空着的训练场。那里比孩子们用的地方大得多，边缘的木桩上还留着许多深浅不一的掌印。

日差走过去，两步以后停下：“悠真。”

“嗯？”

日差抬手重新系紧腕上的护带：“陪我练练吧。”

宁次一下抬起头。悠真看了日差片刻，随后跟了过去。院门后面，那个抱着木刀的孩子也悄悄往前挪了一步。
