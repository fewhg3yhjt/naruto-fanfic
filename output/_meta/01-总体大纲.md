# 总体剧情大纲

## 一、全书核心

日向分家出身的穿越者日向真司，最初的目标不是成为忍界最强，而是解决一个具体而切身的问题：**不能允许另一个人通过一个手印决定自己的生死。**

他从白眼、柔拳和笼中鸟开始，逐步研究查克拉控制、封印、瞳术、血继、身体、自然能量、尾兽和六道力量，最终走出一条以羽村/转生眼体系为核心、属于自己的力量道路。

穿越知识的价值主要是“知道某些终点存在”，而不是直接知道实现方法。随着剧情被改变，原作知识的可靠性持续下降。

## 二、长期三主线

### 1. 力量线

```text
白眼与柔拳
→ 查克拉提炼/凝练/控制
→ 笼中鸟研究
→ 瞳术与封印
→ 血继与医疗
→ 人工经络/傀儡/身体工程
→ 自然能量与仙人体
→ 月球巨大转生眼/羽村查克拉
→ 自有转生眼
→ 三性质融合/血继淘汰
→ 五遁+阴阳
→ 六道仙术
→ 十尾/神树/查克拉生命
→ 血继网罗方向
```

### 2. 人物线

```text
父亲日向宗一：家庭、日向、忍者现实
宇智波弥生：同学→竞争→合作→朋友→战友→重要之人→伴侣
同期忍者：用于真实同龄坐标和各自成长
原作人物：从“知道剧情的人物”逐渐变成真实的人
秘密组织：从救助/研究网络逐步变成战略力量
```

### 3. 时代线

```text
二战后恢复期
→ 三战压力逐步升高
→ 第三次忍界大战
→ 战后暗流
→ 九尾之夜
→ 宇智波危机
→ 晓与尾兽冲突
→ 第四次忍界大战
→ 六道/大筒木
→ 战后技术革命
```

## 三、十三卷结构

### 第一卷《笼中鸟》
年龄约5～7岁。固定12章，建立日向真司、家庭、白眼、查克拉基础、同龄坐标、月球异常、笼中鸟、忍校与宇智波弥生。卷末仍是忍校学生。

### 第二卷《两双眼睛》
约7～10岁。深化忍校生活、白眼与宇智波观察方式、基础忍术、火遁、技术合作和第一代个人战斗体系；卷末成为下忍。

### 第三卷《第三次忍界大战》
约10～14岁。任务升级至战场；弥生在真正损失中觉醒写轮眼；真司的侦察、柔拳和技术体系经受战争检验；秘密网络出现种子。

### 第四卷《战争之后》
约14～16岁。战后伤员、孤儿、雾隐与青的白眼引出笼中鸟异常；真司逐渐取得对自身笼中鸟的真实控制权；研究网络形成。

### 第五卷《血继与身体》
约15～17岁。雾隐血继、傀儡、医疗、大蛇丸、柱间细胞、重吾；研究从“查克拉怎么用”进入“身体为什么能承受这些力量”。

### 第六卷《九尾之夜》
约17岁。九尾、带土、水门、玖辛奈；真司无法解决核心悲剧，但承担大规模救援并第一次看见尾兽级查克拉尺度；再次捕捉月球信号。

### 第七卷《月亮与眼睛》
约18～21岁。空间、封印、远程查克拉、地月锚点；主动连接巨大转生眼，但拒绝把借来的力量当最终答案。

### 第八卷《宇智波》
约21～23岁。止水、鼬、富岳、团藏、宇智波内部派系；救下止水本人但打破别天神“一键和平”可能；从此原作未来大规模失效。

### 第九卷《忍界暗面》
约23～26岁。秘密组织扩展，与晓、带土、大蛇丸、长门形成复杂关系；开始面对“自己是否正在建立另一个强制组织”的问题。

### 第十卷《新的一代》
约26～30岁。鸣人、宁次、佐助、我爱罗、奇拉比；新一代反过来改变真司的技术控制主义。

### 第十一卷《六道之前》
约29～31岁。稳定转生眼、仙人体、三性质融合、尾兽查克拉生命研究、六道理论整合。

### 第十二卷《第四次忍界大战》
约32岁。十尾、轮回眼、斑、带土、鸣人、佐助、六道、辉夜；真司不是单人解决战争，而是让几十年建立的系统全面投入最高强度战场。

### 第十三卷《血继网罗》
战后。羽村、月球、舍人、大筒木、神树、查克拉果实；探索生命和查克拉层级的主动跃迁，进入血继网罗方向。

# 四、第一卷《笼中鸟》详细章节规划

固定12章。本卷不毕业、不接正式任务，时间跨度约5岁到7岁。

## 第一章《白眼》

**中心：** 真司第一次明确自己到底在修炼什么。

- 年龄约5岁。
- 通过日向宗一的家庭训练建立父子关系、日向族地和白眼真实视觉。
- 展示柔拳技术含量，避免“白眼+点穴”的扁平理解。
- 真司已有记录习惯，但方法还不完善。
- 建立基础五项：身体、查克拉量、控制、凝练、白眼。
- 宗一指出身体状态也属于查克拉训练变量。

**禁止：** 月球异常、笼中鸟正式刻印、忍校、弥生。

## 第二章《掌心》

**中心：** 查克拉“量、效率、控制、凝练”不是同一个概念。

- 宗一用掌部训练展示同等查克拉产生不同效果。
- 真司练凝练，出现真实失败和身体疲劳。
- 通过持续记录发现睡眠、饮食、体能影响查克拉状态。
- 明确主角会主动提升查克拉总量，但没有捷径。
- 身体训练正式成为长期基础。

## 第三章《对练》

**中心：** 看得见不等于躲得开。

- 日向和彦正式登场，作为正统日向同龄坐标。
- 真司在正式切磋中明显落败。
- 白眼信息处理、身体反应、步法、动作自动化之间产生矛盾。
- 宗一加入受控动态反应训练。
- 和彦不是反派，也会记录、思考和成长。

## 第四章《月亮》

**中心：** 真司第一次碰到一个远超自己理解的终点。

- 前世记忆让他明确知道白眼存在更高形态“转生眼”。
- 仅知道舍人、羽村、月球、巨大转生眼等模糊结果，不知道实现公式。
- 在正常白眼探索中意外与月球巨大转生眼产生短暂共鸣。
- 出现反向查克拉、轻微重力异常、悬浮、极远处巨大查克拉感。
- 真司误以为自己触发了转生眼。
- 宗一只确认孩子眼部经络过载和现场异常痕迹，无法确认真司的解释。

## 第五章《第五十七次》

**中心：** 成功一次不等于掌握方法。

- 真司尝试复现，但不写成“失败几十次”的统计汇报。
- 选择几个有代表性的变量：输出量、循环路径、身体状态、时间/月相。
- 逐渐形成控制变量与记录方法。
- 研究一度挤占正常修炼，宗一要求重新平衡。
- 真司最终注意到第一次异常可能是“眼睛→身体”的反向供能。
- 暂时形成“能量来源也许在外部”的假设，并降低复现实验频率。

## 第六章《笼中鸟》

**中心：** 原作设定真正落进主角自己的身体。

- 年龄约6岁。
- 宗一主动谈笼中鸟，并讲自己年轻时曾试图破解、差点失明。
- 真司提前记录刻印前的眼部/额部经络。
- 接受笼中鸟时用白眼观察，但看见不代表看懂。
- 发现笼中鸟的一处限制节点与月球异常时活跃的眼部路径重合。
- 只记录为观测/推测，不下“笼中鸟阻止转生眼”的结论。

## 第七章《印》

**中心：** 破解之前，先弄清楚自己不知道什么。

- 笼中鸟恢复期。
- 真司试图对照刻印前后记录，发现绝大多数结构看不懂。
- 宗一阻止危险的直接冲击测试。
- 真司把记录正式分成【观测】【推测】【待验证】。
- “权限”概念可以只出现非常早期的模糊苗头，不在本卷真正破解。
- 准备进入忍校。

## 第八章《忍者学校》

**中心：** 日向之外还有一个真实的木叶。

- 6岁入学。
- 通过从族地去忍校的路径展示木叶普通生活、其他忍族和平民。
- 宇智波弥生正式登场。
- 初次描写自然：外貌印象+神态/动作，不做人物卡。
- 两人只建立“互相注意”，不急着成为好友。

## 第九章《两种聪明》

**中心：** 主角不是唯一的天才，也不是所有项目第一。

- 忍校基础理论、投掷、体术、查克拉课程自然形成同龄比较。
- 真司：理论、控制、观察突出。
- 弥生：动作学习、手里剑、临场反应突出。
- 和彦在日向正统柔拳方向仍保持优势。
- 两人逐渐产生竞争意识，但弥生不能被写成莽撞或提问工具。

## 第十章《火》

**中心：** 两种观察方式开始互补。

- 弥生开始宇智波火遁基础训练。
- 真司第一次系统观察性质变化，但不能看一眼就理解火遁。
- 弥生需要的是白眼提供她自己看不到的反馈，不是让真司“教宇智波火遁”。
- 真司需要弥生提供动态、快速、不同于日向体系的训练样本。
- 出现“真司分析很久，弥生靠身体先做到”的反差。

## 第十一章《半掌》

**中心：** 第一项个人技术只出现“方向”，不直接成熟。

- 真司在移动切磋中无法完成标准柔拳的完整注入。
- 一次失败只送入极少查克拉，却意外让对方动作短暂迟滞。
- 他开始思考：是否并非每次都必须完整封穴。
- 形成短脉冲/短促干扰的实验方向。
- 本章只完成“发现问题+初步验证”。

## 第十二章《七岁》

**中心：** 第一阶段成长完成，但所有真正的大问题仍然没有解决。

- 时间推进至约7岁，可用一次阶段训练或忍校考核承载，不做流水账总结。
- 真司在同龄人中已经明显优秀，但没有全面碾压。
- 和彦正统柔拳仍有优势；弥生形成稳定竞争/合作关系。
- 短脉冲只是雏形。
- 笼中鸟无法破解，月球连接无法复现。
- 真司不再把希望寄托在等待那股力量再次出现，而是继续练当前能够掌握的东西。

- C级及以上正式任务主线。
- 三战战场。
- 写轮眼觉醒。
- 卡卡西/带土/琳深度关系。
- 秘密组织。
- 雾隐血继研究。
- 柱间细胞、大蛇丸合作、重吾。
- 高级人工身体。
- 主动调用巨大转生眼。
- 完整转生眼。
- 影级/超影等元叙事式战力讨论。
