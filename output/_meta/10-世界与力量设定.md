# 世界与力量设定总表

> 只记录已经锁定的底层规则。正文中不直接照搬本文件解释，应通过训练、任务、人物和实验逐渐体现。

# 一、世界运行原则

- 世界不围绕主角转。
- 每个角色和组织只拥有有限信息。
- 组织不是单一意志：日向、宇智波、木叶、雾隐、晓等内部均有不同利益和观点。
- 忍者社会不是现代国家/军队/警察系统的机械映射。
- 大名体系和国家早于忍村；忍村主要集中战略级和专业忍者暴力。
- 普通护卫、商人、地方势力、寺院、贵族和民间秩序长期存在。
- B级及以上任务通常意味着预期忍者敌对风险上升，任务评级取决于已知情报而非上帝视角真实难度。

# 二、查克拉基础

查克拉由身体能量与精神能量结合产生，但正文不把这句话当作完整科学公式。

主角前期区分：

1. **总量**：可动用储备规模。
2. **提炼效率**：身体/精神状态转化为可用查克拉的效率。
3. **控制**：已经产生的查克拉能否按意图使用。
4. **凝练**：同量查克拉在流动和作用时保持集中、稳定的能力。
5. **身体承载**：经络、组织、生命力能否承受更高密度和更高输出。

原则：效率高不能无限替代总量，总量大也不能替代控制。

# 三、白眼

白眼核心优势：
- 大范围视野。
- 透视。
- 查克拉经络/穴位观察。
- 对内部结构和自身训练反馈特别强。

固定限制：
- 看见不等于理解。
- 距离、精度、持续时间、信息处理能力存在权衡。
- 高速战斗中身体和脑处理速度可能跟不上眼睛。
- 不具备天然读心、万能术式解析等能力。

# 四、柔拳

柔拳不只是“按穴位按钮”。

其核心包括：
- 接近和步法。
- 查克拉从自身穴位释放。
- 接触瞬间的凝练和注入。
- 对敌方经络/穴位的干扰。
- 不同攻击深度、范围、目的。

真司早期个人路线：从完整点穴向“短促、低量、高精度的局部干扰”探索，但第一卷只形成雏形。

# 五、笼中鸟（小说补充模型）

### 控制层
宗家通过外部触发获得疼痛、干扰甚至致命权限。

### 锁层
封印深度绑定脑部、眼部和查克拉经络，不是去掉额头图案就能解除。

### 死亡保护层
特定条件下破坏/保护白眼，防止死后被直接夺取。

### 长期补充假设
原始术式可能还承担白眼稳定/安全阀功能，后被制度化为分家控制工具。

### 破解路线
1. 欺骗控制触发。
2. 夺回权限，移除外部致命控制。
3. 重构/决定是否保留必要的稳定与死亡保护功能。

# 六、转生眼

## 三道门槛

### 1. 眼
兼容且足够纯的白眼结构，以及正确眼部查克拉变化；笼中鸟限制最终必须处理。

### 2. 查克拉性质
普通查克拉“更多”不能代替羽村/大筒木层级的特殊性质。

### 3. 身体
身体必须承受高密度查克拉、引力相关能力和转生眼查克拉模式。

医疗、柱间细胞、重吾/自然能量等主要解决身体与兼容问题，不直接等于“转生眼钥匙”。

# 七、月球巨大转生眼

第一卷异常不是主角自行觉醒。

真相：真司在特定状态下意外成为巨大转生眼的远程终端。

长期主题：

```text
借来的力量
→ 寻找连接
→ 理解连接
→ 拒绝依赖连接
→ 让同等级力量成为自身结构
```

真司后期即使可以借用月球巨大力量，也会把“依赖远程终端”视为另一种笼中鸟。

# 八、柱间细胞

不是万能外挂，也不是转生眼直接钥匙。

研究价值：
- 生命力。
- 细胞活性。
- 阳性质。
- 查克拉承载与恢复。

真司长期目标是理解并分离“高生命力/低侵蚀性”的有效机制，而不是直接注射原始柱间细胞。

# 九、重吾与自然能量

核心问题：重吾的身体为何无需标准冥想流程也能自动吸收自然能量？

路线：

```text
重吾体质
→ 自然能量感知
→ 自动吸收机制
→ 身体适应
→ 稳定仙术查克拉
→ 仙人体工程方向
```

# 十、查克拉量长期路线

真司前期不是巨量查克拉天才。

```text
减少浪费/提升效率
→ 身体成长与训练
→ 储能封印
→ 人工储存/查克拉核心
→ 自然能量
→ 尾兽/查克拉生命理解
→ 转生眼与六道层级输出
```

人工结构不允许“凭空生产无限查克拉”。能量必须有来源：储存、传输、生物生产或自然能量转换。

# 十一、血继研究

血继不是收集宠物式能力库。

重点是通过不同血继回答基础问题：
- 双性质如何真正融合？
- 查克拉如何改变组织和器官？
- 感知型血继如何读取外界？
- 情绪/脑部变化如何改变瞳术？

逐渐形成血继数据库。

# 十二、尾兽

尾兽不是九个电池。

它们分别用于理解：
- 查克拉量的真实尺度。
- 查克拉能否携带人格/生命信息。
- 人柱力控制与合作的差别。
- 尾兽死亡/复生与查克拉生命结构。

# 十三、血继淘汰与血继网罗

三性质融合不是“三个遁术同时释放”，而是形成新的统一查克拉性质。

真司长期工作方向暂定风+雷+水，形成干扰查克拉循环/破坏忍术结构的特殊场域，但名称和完整机制尚未锁死。

血继网罗更不是“七属性都学会”。需要完整转生眼、仙人体、六道仙术、五遁阴阳统一、高阶融合能力、十尾/神树查克拉生命理解，以及自身查克拉性质向大筒木层级跃迁。
