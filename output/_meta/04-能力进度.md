# 日向真司

## 当前阶段：第一卷第三章完成后（约5岁半）

### 身体

- 基础体能：接受日向儿童训练。
- 力量：儿童水平。
- 速度：儿童水平中的较好者，但与成年忍者无可比性。
- 耐力：正在培养。
- 步法：基础。
- 动态反应：弱于白眼提供的信息速度。

### 查克拉总量

- 同龄日向中上。
- 不具备鸣人/尾兽/千手柱间式天然巨量储备。
- 可以通过身体成长、提炼效率和长期训练缓慢增加。

### 查克拉提炼

- 会基础方法。
- 已开始记录睡眠、饮食、体能、精神疲劳对提炼结果的影响。
- 记录仍是个人观察，不能当作精确测量体系。

### 查克拉控制

- 同龄优秀。
- 优势来自白眼可直接观察自身查克拉流动和穴位释放。
- 尚未达到医疗忍者式超精细控制。

### 查克拉凝练

- 已在宗一指导下理解“集中、稳定”与“强行堵住”的区别。
- 能让很小一股查克拉在掌心短暂稳定。
- 仍然容易过松而泄露，或过紧而反冲。

### 白眼

已掌握：
- 开启/关闭。
- 基础透视。
- 主要经络与穴位观察。
- 基础周围视野。

当前缺陷：
- 持续时间有限。
- 远距离和高精度不可兼得。
- 高速环境中信息处理能力差。
- 看见复杂术式不等于理解。

尚未发生：
- 月球巨大转生眼共鸣。
- 羽村查克拉特征。
- 主动重力能力。

### 柔拳

已掌握：
- 儿童基础架势。
- 掌部基础查克拉释放。
- 基础穴位认知。

正在学习：
- 凝练。
- 步法。
- 让观察转化为反应。
- 在移动中维持掌部查克拉。

尚未掌握：
- 高阶八卦掌。
- 回天。
- 空掌。
- 稳定短脉冲干扰。

第三章实际表现：一次短暂造成和彦动作迟滞，无法连续使用，尚未命名。

### 封印

- 几乎没有实际能力。
- 仅知道封印术存在。
- 笼中鸟研究必须等亲身刻印后才真正开始。

## 第一卷允许成长上限

卷末约7岁：

- 身体：同龄优秀。
- 查克拉量：中上，持续增长但无异常跃升。
- 提炼效率：同龄顶尖梯队。
- 控制：同龄顶尖梯队。
- 凝练：日向同龄优秀。
- 白眼：观察能力突出，高速处理仍有明显限制。
- 柔拳：基础扎实，开始形成“短促查克拉干扰”的个人方向，但尚非成熟术式。
- 笼中鸟：完成结构记录，无法破解。
- 月球：发生一次被动共鸣，无法复现。

## 第一卷绝对禁止提前出现

- 以五岁身体和成年上忍“过十招”。
- 真实击败成年忍者。
- 无铺垫掌握高级柔拳。
- 直接破解笼中鸟。
- 主动调用巨大转生眼。
- 转生眼查克拉模式。
- 仙术、柱间细胞、重吾路线。
- 人工身体/傀儡分身。
- 血继淘汰。
- 尾兽级查克拉储量。

# 日向宗一

- 成年日向分家忍者。
- 柔拳、白眼、任务经验均远高于真司。
- 对儿童训练会主动压低速度、力量、查克拉和招式复杂度。
- 真司训练中“躲开父亲几次”只能发生在明确受控条件下，不能用于推断真实战力接近。

# 日向和彦

第一卷计划：
- 正统柔拳基础优于真司。
- 身体协调和动作自动化优于真司。
- 白眼分析/查克拉精细控制略逊于真司。
- 他同样会持续成长，不作为静态标尺。

# 宇智波弥生

第一卷计划：
- 查克拉量可略优于真司。
- 手里剑、动作模仿、临场反应优于真司。
- 精密查克拉控制不如真司。
- 尚未觉醒写轮眼。
- 火遁训练属于宇智波家族体系，真司只能观察和反馈，不能取代家族教学。
