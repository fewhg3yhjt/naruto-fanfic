# 火影同人小说项目说明

## 目录约定

所有生成内容位于 `output/`。

正文按卷建立目录，每章一个 Markdown 文件：

```text
output/
├─ _meta/
├─ 第一卷 笼中鸟/
│  ├─ 第一章 白眼.md
│  ├─ 第二章 一份查克拉.md
│  └─ ...
├─ 第二卷 两双眼睛/
└─ ...
```

正文文件统一命名：

```text
第X章 章节名.md
```

正文文件只保存小说正文，不混入分析、修改说明、状态记录或提示词。

## `_meta` 文件职责

| 文件 | 作用 | 更新频率 |
|---|---|---|
| `01-总体大纲.md` | 全书十三卷和当前卷章节规划 | 卷规划变化时 |
| `02-当前状态.md` | 故事当前时点的快照 | 每章后 |
| `03-人物关系.md` | 主要人物双向关系与关系阶段 | 有变化时 |
| `04-能力进度.md` | 各角色当前能力、训练中能力、禁止提前能力 | 每章后检查 |
| `05-伏笔与未解决问题.md` | 长线伏笔、角色认知、计划回收位置 | 有变化时 |
| `06-时间线.md` | 年龄、事件、原作关键节点 | 时间推进时 |
| `07-写作范式.md` | 文风、句式、环境、人物、训练、战斗标准 | 风格调整时 |
| `08-章节记录.md` | 每章发生了什么、状态变化、偏离大纲情况 | 每章后 |
| `09-角色情报边界.md` | 每个人知道什么、不知道什么、误判什么 | 有情报变化时 |
| `10-世界与力量设定.md` | 查克拉、白眼、笼中鸟、转生眼等底层规则 | 设定变化时 |

## 正式连续性规则

当前对话中已经生成的第一至第六章均属于**试写稿**，不自动视为正式正文。

只有实际保存到对应卷目录，并在 `08-章节记录.md` 标记为“正式完成”的章节，才进入小说连续性。

## 每章生成流程

1. 读取当前卷大纲。
2. 读取当前状态。
3. 检查人物关系。
4. 检查能力进度与年龄限制。
5. 检查伏笔和角色情报边界。
6. 检查时间线。
7. 按写作范式生成正文。
8. 保存为 `第X章 章节名.md`。
9. 更新状态、关系、能力、伏笔、时间线和章节记录。

原则：**大纲约束方向，状态约束连续性，设定约束可能性，写作范式约束正文质量。**
